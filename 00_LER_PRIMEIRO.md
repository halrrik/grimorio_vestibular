# 00 — Ler Primeiro

Este arquivo deve ser lido antes de qualquer planejamento, alteração ou execução dentro do Grimório Vestibular.

## Regra central

Todo novo Grimório ou evolução de Grimório começa por uma hipótese.

O trabalho de desenvolvimento deve permanecer ligado à hipótese até que ela seja validada, invalidada ou ajustada.

Propostas úteis que não pertencem à hipótese atual devem ir para `futuro/00_FISHBOWL.md`, não para o fluxo principal.

## Como operar

1. Leia este arquivo.
2. Leia `01_INDICE_GERAL.md`.
3. Leia `02_REGRAS_GLOBAIS.md`.
4. Leia `03_HIPOTESE.md`.
5. Só então proponha mudanças.

## Ordem dos arquivos

O Grimório usa arquivos numerados no padrão `##_NOME_DO_ARQUIVO.md` para facilitar a ordem de leitura por humanos e por IA.

Nunca remover a numeração dos arquivos essenciais.
