# Fishbowl — Ideias e Pendências Futuras

Este arquivo guarda ideias, melhorias e pendências que não entram automaticamente no fluxo principal do MVP atual.

Regra: uma ideia no Fishbowl não está aprovada para implementação. Ela existe para ser revisada, priorizada ou descartada depois.

## Pendências do MVP1

### Revisar scripts de fala do Grimório

Status: pendente.
Prioridade: média.
Motivo: o MVP1 precisa testar o fluxo real antes de fixar frases definitivas.

Melhorar e revisar scripts recomendados para cada etapa do processo:

- início do estudo;
- perguntas durante o estudo;
- pedido de leitura prévia;
- salvamento no Grimório;
- confirmação antes de salvar;
- geração de quiz;
- correção do quiz;
- cálculo de absorção;
- recomendação de próxima ação;
- preparação de commit.

Observação: por enquanto, o Grimório deve seguir o fluxo aprovado e adaptar a fala ao contexto. Um script recomendado completo será criado depois que a Gabi testar o alpha.

### Script recomendado de uso

Status: pendente.
Prioridade: média.

Criar um roteiro sugerido de falas para orientar a Gabi no uso diário do Grimório Vestibular.

O roteiro deve cobrir:

1. como iniciar um estudo;
2. como pedir explicações;
3. como pedir questões;
4. como pedir para salvar;
5. como aprovar ou ajustar uma captura;
6. como pedir quiz;
7. como responder quiz;
8. como pedir correção;
9. como aprovar commit.

Critério de aprovação futura: o roteiro deve ajudar sem deixar o uso rígido demais.
