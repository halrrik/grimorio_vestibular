# 01 — Padrão Grimório

## Princípio

O Grimório é um método reutilizável. Cada versão deve adaptar o conteúdo ao cenário, sem quebrar a base comum.

## Base obrigatória

- Hipótese explícita.
- Arquivos numerados `##_`.
- Índice geral.
- Regras globais.
- Patch log.
- Fishbowl para ideias fora do escopo.

## Regra de desenvolvimento

Toda proposta deve responder:

1. Qual hipótese atende?
2. Qual resultado esperado melhora?
3. Está no MVP atual ou deve ir para o Fishbowl?
