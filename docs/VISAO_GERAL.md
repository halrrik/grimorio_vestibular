# Visão Geral

O Grimório Vestibular é uma base de estudo e automação educacional para vestibulares brasileiros.

Ele deve funcionar como um sistema organizado em quatro camadas:

1. Conteúdo: matérias, temas, resumos e mapas mentais.
2. Prática: questões, listas, simulados e correções.
3. Revisão: flashcards, revisão espaçada e retomada de erros.
4. Agente: instruções, regras e fluxos de interação com IA.
