# 00 — MVP1

## Objetivo

Testar se o estudo livre em chat pode virar memória útil do Grimório Vestibular usando Markdown.

## Fluxo aprovado

1. Gabi estuda em chat.
2. Pede para salvar no Grimório.
3. Grimório pergunta/confirma.
4. ChatGPT gera ou atualiza arquivo Markdown.
5. Gabi aprova.
6. ChatGPT faz commit se houver permissão operacional.
7. Caso não haja permissão, entrega arquivos e comandos como fallback.

## Componentes do MVP1

- Captura Grimório.
- Quiz diagnóstico.
- Correção do quiz.
- Absorção estimada e medida em escala de 0 a 100.
- Patch log.
- Índice de estudos.
- Dúvidas ativas.
