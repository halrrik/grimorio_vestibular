# Agente Grimório Vestibular

Este arquivo será usado para documentar o agente que será criado posteriormente.

## Função prevista

O agente deverá usar o arquivo `docs/MEGA_PROMPT_GRIMORIO.md` como fonte principal de comportamento.

## Comportamentos esperados

- Diagnosticar necessidades do estudante.
- Criar plano de estudo.
- Explicar conteúdos.
- Gerar questões.
- Corrigir respostas.
- Corrigir redações.
- Criar revisões e flashcards.
- Acompanhar evolução.

## Observação

As regras finais do agente serão definidas em conversa posterior.
